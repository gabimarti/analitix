Instalar en Windows

No necesitas conocimientos técnicos ni permisos de administrador.

  1. Descarga el instalador con el botón verde de arriba. Se guardará en tu carpeta Descargas.
  2. Ábrelo con doble clic. Si Windows muestra un aviso azul, lee el recuadro de abajo.
  3. Sigue el asistente. Te preguntará dónde guardar tus datos (por defecto, en Documentos).
  4. Abre Analitix desde el menú Inicio y crea tu contraseña. Guárdala bien: si la olvidas, no hay forma de recuperar los datos.
  5. Importa tus analíticas: copia los PDF en la carpeta informes_analiticas y usa Archivo → Importar.

⚠ «Windows protegió su PC»

Al abrir el instalador, Windows puede mostrar este aviso azul. Aparece porque el instalador no tiene una firma digital de pago, no porque sea peligroso: Analitix es de código abierto y cualquiera puede revisar su código.

Para continuar, pulsa Más información y después Ejecutar de todas formas.

Si quieres comprobar que el fichero no se ha alterado, compara su huella SHA-256 con la de SHA256SUMS.txt.

Para actualizar, descarga el instalador nuevo y ejecútalo encima: tus datos se conservan.
